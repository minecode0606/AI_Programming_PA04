# Low-Data Probing of LLM Reasoning Robustness Using PCA and RBF-SVM

GitHub-ready code, metadata, and archived results for our AIMO Interpretability
Challenge study. A frozen `DeepSeek-R1-0528-Qwen3-8B` backbone supplies layerwise
residual-stream activations. Our main probe uses last-token layer updates,
principal component analysis (PCA), optional geometry features (L2 norms and
adjacent-layer cosine similarities), and an RBF-SVM. The repository also
preserves LSTM, XGBoost, and ablation experiments.

> **Artifact completeness:** The input archive contains the labeled CSV,
> source scripts, extraction manifest and some saved result CSVs. It **does not**
> contain raw `.npy` activations, an extraction configuration JSON, or trained
> probe checkpoints. No substitutes have been invented. The pretrained
> backbone is available from its official Hugging Face model page, and the
> missing experiment files can be regenerated by the provided code.

## 1. Clone the repository

```bash
git clone https://github.com/<OWNER>/<REPOSITORY>.git
cd <REPOSITORY>
```

Replace `<OWNER>` and `<REPOSITORY>` with your **actual** GitHub coordinates.
The placeholders are intentional; the original archive provides no repository URL.

## 2. Set up the Conda environment

```bash
conda env create -f environment.yml
conda activate aimo-robustness
```

Versions are pinned in `environment.yml` to help reproduce the Python
environment. They are specified for packaging and have **not** been
validated end-to-end on every operating system and accelerator.
For a different CUDA environment, follow the official PyTorch installation
instructions and update the torch build accordingly.

## 3. Source data and model weights

The **actual provided dataset** is:

```text
data/processed/math-robust-qwen-problems.csv
```

It contains 142 labeled problems: 36 robust and 106 spurious (True/False).
The `artifacts/deepseek_r1_qwen3_8b_tat/manifest.csv` records prior activation
extraction metadata but is **not** a replacement for the missing `.npy` data.
Full data provenance, preprocessing and splits are in [data/README.md](data/README.md).

The pretrained backbone (not the trained probe) is here:

**https://huggingface.co/deepseek-ai/DeepSeek-R1-0528-Qwen3-8B**

`src/extractor.py` downloads the backbone automatically on first run.
See [checkpoints/README.md](checkpoints/README.md) for the explicit download
command, the missing fitted checkpoint status, and the regeneration workflow.

## 4. Regenerate the activation arrays

Run the following from the **repository root**, on a system with adequate
RAM, disk space, and an accelerator suitable for the 8B BF16 backbone:

```bash
python src/extractor.py
```

This reads `data/processed/math-robust-qwen-problems.csv` and stores
`.npy` activations, token IDs and `extraction_config.json` at:

```text
artifacts/deepseek_r1_qwen3_8b_tat/
```

**Do this before training or evaluating.** These generated binary arrays
are excluded from Git by `.gitignore` to avoid publishing multi-GB files.
For exact extraction behavior, refer to the source code and manifest fields.

## 5. Reproduce the RBF-SVM experiment

```bash
PYTHONPATH=src python src/grid_search_rbf.py
```

The code runs nested, group-aware cross-validation and a final grid search.
Its result directory is `artifacts/rbf_gridsearch/`. It writes fold metrics,
out-of-fold predictions, reports, best parameters, and a fitted final
`final_best_model.joblib` (not distributed with the input archive).

## 6. Reproduce comparison experiments and ablations

Run individually from the repository root **after activation extraction**:

```bash
PYTHONPATH=src python experiments/baselines.py
PYTHONPATH=src python experiments/ablation.py
PYTHONPATH=src python experiments/geometry_ablation.py
PYTHONPATH=src python experiments/xgboost_comparison.py
```

These retain the full original implementations, renamed and relocated:

| Experiment | Original source filename | Main output directory |
| --- | --- | --- |
| RBF-SVM vs. LSTM | `rbf_vs_lstm.py` | `artifacts/last_rbf_vs_lstm/` |
| Token pooling/classifier ablation | `ablation_compare.py` | `artifacts/tat_pca_ablation/` |
| Norm/cosine feature ablation | `axabaltion.py` | `artifacts/geometry_ablation/` |
| XGBoost comparison | `xgbost_pca_comp.py` | `artifacts/xgboost_comparison/` |

These scripts include inference on held-out folds and quantitative evaluation;
several saved CSV tables from the original ZIP are already in `artifacts/`.

## 7. Run inference from a newly fitted probe

After the RBF-SVM training script has produced the final `.joblib` model:

```bash
PYTHONPATH=src python src/inference.py \
  --model artifacts/rbf_gridsearch/final_best_model.joblib \
  --artifact-dir artifacts/deepseek_r1_qwen3_8b_tat \
  --output artifacts/rbf_gridsearch/inference_predictions.csv
```

This predicts labels for the extracted activation dataset. It does not
classify raw problem text without first running the backbone extractor.

## 8. Expected results and reproducibility notes

The included original paper and README report five-fold mean balanced
accuracy of **0.732** for the PCA + RBF-SVM method on **142** labeled samples.
Original result tables, OOF predictions where supplied, and fold metrics
can be inspected under `artifacts/`. These are **historical saved outputs**;
this repackaging does not claim to have re-run or verified the full experiments.

- **Seeds/splits:** Random seed 42; nested grouped CV, typically outer 5
  folds and inner 3 folds. Split construction lives in each script.
- **Preprocessing:** BF16 backbone inference, per-sample residual-state
  extraction, TaT displacement trajectories, last-token pooling, fold-fitted
  PCA and optional geometry features; scaler and classifier fit within CV.
- **Hardware:** GPU acceleration and sufficient memory are recommended for
  the 8B BF16 backbone (model files ~16.4 GB; budget additional runtime GPU
  memory and disk for activations). The RBF-SVM/XGBoost probes themselves
  are much smaller. Exact runtime hardware was not in the source ZIP.
- **Dataset:** 142 examples with class imbalance (36 vs 106). This archive
  does not provide an independently downloadable complete activation bundle.
- **Checkpoints:** The DeepSeek model weights are downloadable, but the
  trained **robustness probe** must be rebuilt from the code.
